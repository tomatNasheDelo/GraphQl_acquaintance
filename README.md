# Spring Boot GraphQL — знакомство

Минимальный backend-проект на Java и Spring Boot для знакомства с GraphQL. Без frontend и базы данных: данные хранятся в памяти и сбрасываются при перезапуске.

В корне проекта находится [`start.txt`](start.txt) с описанием элементов, кратким введением в GraphQL, командами запуска и примерами запросов.

Быстрый старт при установленном JDK 17+ и Gradle 8.10+:

```bash
gradle bootRun
```

GraphQL endpoint: <http://localhost:8080/graphql>. Примеры запросов — в `start.txt`.
